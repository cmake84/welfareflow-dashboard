# 통진프란치스꼬집 생활재활 대시보드 — 로컬 사용 안내

## 들어 있는 것

- `통진프란치스꼬집-생활재활-대시보드.html` — 프로그램 본체입니다. 이 파일 하나가 전부입니다.
- `사용안내.md` — 지금 읽고 계신 문서입니다.

설치할 것이 없습니다. 압축을 푼 폴더 어디에 두어도 되고, 파일을 다른 곳으로
옮기거나 이름을 바꿔도 그대로 동작합니다.

## 여는 법

압축을 푼 뒤 `통진프란치스꼬집-생활재활-대시보드.html` 을 두 번 누르면
기본 브라우저에서 열립니다. 자주 쓰신다면 브라우저 즐겨찾기에 등록해 두세요.

**Chrome 또는 Edge 를 권합니다.** 아래 '기록을 파일로 저장하기'가
이 두 브라우저에서만 동작합니다.

인터넷 연결 없이 동작합니다. 다만 연결이 없으면 글꼴이 시스템 기본 글꼴로
바뀝니다. 기능에는 영향이 없습니다.

## 기록이 저장되는 곳

입력하는 즉시 **그 브라우저 안에** 자동으로 저장됩니다. 창을 닫거나 컴퓨터를
꺼도 남아 있고, 다음에 같은 파일을 열면 그대로 이어집니다.

주의할 점이 두 가지 있습니다.

- 브라우저를 바꾸면(Chrome → Edge) 기록이 따라가지 않습니다. 브라우저마다
  따로 저장합니다.
- 브라우저의 '인터넷 사용 기록 삭제'에서 쿠키·사이트 데이터까지 지우면
  기록도 함께 지워집니다.

그래서 아래 두 가지 중 하나는 꼭 해 두시길 권합니다.

## 기록을 파일로 저장하기 (Chrome · Edge)

맨 아래 **내보내기 · 백업 → 로컬 파일에 자동 저장 → 저장할 파일 만들기** 를
누르고, 기록을 담을 `.json` 파일을 원하는 폴더에 하나 만들어 두세요.
그 뒤로는 입력할 때마다 그 파일이 자동으로 갱신됩니다. 화면 위쪽 저장 표시줄에
파일 이름과 마지막 저장 시각이 나옵니다.

다음에 다시 열었을 때는 같은 자리에 **다시 연결** 버튼이 나옵니다. 한 번
눌러 파일 접근을 허용하면 이어서 자동 저장합니다. (브라우저 보안상 매번
한 번의 확인이 필요합니다.)

이 파일을 공유 폴더나 백업 대상 폴더에 두면 기록이 함께 보관됩니다.

## 수동 백업 (모든 브라우저)

**내보내기 · 백업 → 데이터 백업 → 백업 파일 받기** 를 누르면 전체 기록이
`.json` 파일 하나로 저장됩니다. 다른 컴퓨터에서 **백업 불러오기 → 파일 선택**
으로 읽어 들이면 그대로 옮겨집니다.

Firefox 나 Safari 를 쓰신다면 자동 저장이 없으므로, 근무 마칠 때 이 백업을
받아 두시는 편이 안전합니다.

## Word 문서로 출력

**내보내기 · 백업 → Word 문서로 내보내기** 에서 '이번 달 전체' 또는
'오늘 하루' 를 고르고 받으면 `.docx` 파일이 만들어집니다. 안에는

1. 일일 생활기록 (날짜 · 이용인 · 식사 · 정서 · 활동 참여 · 활력징후 · 특이사항 · 작성자)
2. 교대 인수인계
3. 프로그램 운영 실적과 회기별 관찰 기록
4. 월간 과업 진행

네 가지가 표로 들어갑니다. 표지에 기관명 · 기간 · 출력 일시 · 출력자가 붙습니다.
한글 워드프로세서에서도 열립니다.

## 화면 구성

- **머리단** — 근무 일자, 근무조(주간조 · 야간조), 작성자를 고릅니다. 한 번
  고르면 네 탭 전체에 적용되고, 작성자는 그 브라우저에 기억됩니다.
  오른쪽 점과 문구가 지금 어디에 저장되고 있는지 알려 줍니다.
- **인수인계** — 대상 이용인 · 중요도 · 내용을 적으면 근무 방향이 자동으로
  붙습니다. 다음 조가 '확인함' 을 누르면 누가 언제 받았는지 남습니다.
- **생활기록** — 이용인별 카드에 식사 · 정서 · 활동 참여 · 활력징후(BP · PR ·
  BT · BST) · 특이사항을 넣습니다. 입력하는 즉시 저장됩니다.
- **프로그램 회기** — 회기를 기록하면 그 달의 운영 횟수와 연인원이 자동으로
  집계됩니다. 프로그램 목록은 직접 추가 · 수정 · 삭제할 수 있습니다.
- **월간 과업** — 영역별 표준 과업이 매달 자동으로 깔립니다. 담당자를 지정하고
  완료를 체크하면 진행률이 보입니다.

## 명단 고치기

- **이용인** — 생활기록 탭 아래쪽 '이용인 명단 관리'
- **직원** — 머리단의 '직원 명단' 버튼

이름을 바꾸면 지난 기록에서 '누구에 대한 기록인지'는 새 이름으로 함께 바뀌고,
'누가 썼는지' 서명은 그때의 사실이므로 그대로 둡니다. 명단에서 지워도 이미
남은 기록은 지워지지 않습니다.

같은 이름을 두 번 등록할 수 없습니다. 기록이 이름으로 묶이기 때문입니다.
동명이인이 계시면 `김민수(A동)` 처럼 구분해서 넣어 주세요.

## 작성자를 아직 고르지 않았다면

입력은 그대로 저장되고, 서명 자리만 '작성자 미지정' 으로 남습니다. 화면 위에
붙어 있는 안내줄에서 이름을 고르면 그때까지 입력한 것들의 서명이 채워집니다.

## 팀과 함께 쓰려면

이 로컬 파일은 그 컴퓨터에만 저장합니다. 여러 사람이 같은 내용을 실시간으로
보려면 웹 대시보드를 쓰시고, 두 곳 사이에 기록을 옮길 때는 위의 백업 파일을
거치세요.

## 다루실 때 유의할 점

이용인의 건강 상태와 생활 기록이 담기는 파일입니다. 공용 컴퓨터에 두지 마시고,
백업 파일도 기관 규정에 맞는 위치에 보관해 주세요.
